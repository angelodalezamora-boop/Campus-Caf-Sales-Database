# Project 2 · Campus Café Sales Database

A normalized SQLite database with SQL analysis, charts and data interpretation. The web page loads the real `.db` file in the browser (sql.js / WebAssembly), so it works on any static host with no backend.

**Live page:** `project2/index.html` (open through GitHub Pages or a local server)

## Files
| File | Purpose |
|---|---|
| `index.html` | Dashboard, interpretation, schema view and SQL playground |
| `cafe_sales.db` | The SQLite database (6 tables, about 3,600 orders of sample data) |
| `schema.sql` | Table definitions, keys, constraints, indexes |
| `queries.sql` | The 10 analysis queries used on the page, plus one menu-review query |
| `build_db.py` | Regenerates the database (`python build_db.py`, fixed random seed) |

## Database design
`categories`, `payment_methods`, `customers`, `products`, `orders`, `order_items` in third normal form. `order_items.unit_price` stores the price at the time of sale.

## Run locally
Browsers block loading the `.db` from `file://`. Use VS Code Live Server, or:

    python -m http.server 8000

then open (http://127.0.0.1:5500/index.html#projects)

## Testing notes
- All queries run without errors and foreign keys check clean (`PRAGMA foreign_key_check`).
- The playground only accepts `SELECT` queries and runs on an in-memory copy.

## Data note
The data is sample data generated by `build_db.py`. It is not real sales.
